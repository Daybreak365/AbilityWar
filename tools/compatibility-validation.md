# 전체 버전 호환 검증

2026-10-27 기준, Minecraft 1.12.2 이후 26.3까지의 정식 릴리스 계열을 대상으로 Paper·Spigot·CraftBukkit 호환 모듈을 구성했습니다. 기존 13개 모듈에 빠져 있던 15개를 추가하여 통합 JAR에 28개를 포함합니다. 프리릴리스·미래 버전은 자동으로 지원하지 않습니다.

검사한 통합 JAR: `AbilityWar-26.0.0.jar`

SHA-256: `a6ee842db6827046e6beb1e23922b46aa0ab848e57f911f3ec242fe4ad0e98fb`

## 자동 빌드 검사

- Maven `verify` 52개 통과: 버전 판별 6개, 공통 코드 36개, 실제 배포 JAR 검사 10개.
- 공식 Paper 매핑 변환 단위 검사 4개 통과.
- 28개 필수 모듈과 버전 판별 목록 일치, 중복 ZIP 항목 없음, 공통 Plugin 및 현재 소스로 다시 빌드한 20개 모듈의 클래스 보존 확인.
- 구형 Paper 변환기가 모든 클래스를 읽을 수 있도록 배포 JAR의 클래스 버전을 Java 21 이하로 검사. 서버 실행 요구사항은 별도이며 26.x는 Java 25가 필요합니다.
- 재매핑 후 `IDummy`·`IWorldBorder` 공개 메서드 이름 보존 검사. 과거의 잘못된 더미 메서드 이름과 Java 25 클래스가 포함된 JAR로 검사 실패도 확인했습니다.

## 검증 범위와 남은 기존 결함

- 위 표에 없는 개별 패치 버전은 같은 NMS 계열의 모듈을 선택하지만, 개별 서버 실행 검증까지 했다는 의미는 아닙니다.
- Paper 1.13.1, 1.14, 1.14.1, 1.14.2, 1.14.3, 1.15, 1.15.1, 1.16.2, 1.16.4, 1.17, 1.19, 1.19.1의 공식 Paper 파일은 체크섬을 확인했습니다. 그러나 부트스트랩에 필요한 Mojang 원본 다운로드가 HTTP 503으로 실패하여 서버를 실행하지 못했습니다.
- Paper 아카이브에 1.20.3·1.21.2·26.1 등이 없으며, 일부 BuildTools 릴리스 별칭은 같은 계열의 최신 패치로 연결됩니다. 실제 로그에 표시된 서버 버전만 실행 검사 결과로 기록했습니다.
- Spigot 1.20.6 별도 소스 빌드는 정확한 `bungeecord-chat:1.20-R0.2` 의존성 다운로드 실패로 끝까지 실행하지 못했습니다. 같은 버전 CraftBukkit과 Paper는 최종 파일로 통과했습니다.
- CraftBukkit 1.20.6은 공식 소스·공식 BuildData 매핑·SpecialSource·정확한 라이브러리 바이트를 사용해 빌드했습니다. 다운로드 장애 때문에 테스트 체크아웃의 일부 의존성 기술자만 검증된 Paper 번들의 로컬 좌표로 대체했고, 생성된 CraftBukkit Main을 실제 런타임 라이브러리와 직접 실행했습니다. 플러그인 소스나 배포 JAR에 서버 라이브러리를 넣지 않았습니다.
- 변경하지 않은 1.13–1.16 모듈에는 따옴표·줄바꿈을 포함한 홀로그램 문구를 JSON으로 만들 때 예외가 발생하는 **기존 결함**이 남아 있습니다. 기본 호환 검사와 별도 문자열 검사로 구분하여 기록했습니다. 이번에 재빌드한 1.17 이후 모듈은 문자열 검사도 통과했습니다.
- 자동 검사는 실제 온라인 클라이언트의 화면·조작, 모든 외부 애드온의 동작이나 다인전 성능까지 검증하지 않습니다.
